# StrikeBlink

One-click Solana Actions / Blinks for short-dated strike prediction markets on PREDICT's public devnet pm-AMM.

**MLH Solana Hackathon** entry (Fri Nov 6 12:00 PM ET – Sun Nov 8 11:45 AM ET final submit).

## Rules note

All feature code in this repo is written during the event window. Idea is allowed under MLH rule 7. StrikeBook (`LMH-Solutions/strikebook`) is a separate prior project and is **not** part of this submission; no StrikeBook source is copied here. This app may call third-party packages (`@pm-amm/sdk`, Solana Actions) and may trade markets that happen to exist on the public pm-AMM.
